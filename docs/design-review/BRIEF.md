# Interactive design review contract

Mode: Operate, with Read behavior for clinical reasoning.

This isolated prototype implements the user's chosen conventional clinical-workspace direction, confirmed over the preceding review rounds. It is code-first by explicit request. No new concept tournament or image-generated design authority is appropriate.

## First viewport and interaction

Submission foregrounds the case editor and a compact guidance column. Results foreground the summary, visible differential reasoning, and a priority column. The review-only toolbar exposes all states and light/navy header comparison. It is not part of the proposed production interface.

The signature interaction is the honest submitted/queued/processing/ready timeline. Only the active clock/gear animates; reduced motion disables animation. No percentage implies unavailable progress data.

## Visual contract

Source Sans 3 400/600: 16px body, 14px secondary, 18px section headings, 24px title. Source Code Pro for identifiers and ICD-10 codes only. Neutral light header by default; restrained navy alternate for comparison. White reading surface and subtle gray grouping, blue actions. No ornamental icons, colored side stripes, nested cards, oversized verification, or universally bordered sections. Short reasoning stays visible. Inline small code/check status remains beside each diagnosis. Warning color does not encode likelihood.

## Required coverage

Text and PDF entry, file removal and input validation; preparing services, queued and processing; full results with verified and unverified examples; connection error and failed job; empty and long results; narrow responsive layout; copy and print. Three prominent fictional examples prefill the editor. A dismissible visual invitation opens on a fresh landing-page load and can be replayed from How it works. A framed, input-first demo offers a visible cursor and pause/next/exit controls. No analysis service requests or case persistence. Preview sample data remains explicitly fictional, labeled outside the clinical narratives. Code links navigate to NLM MedlinePlus only when clicked; the worker fallback is likewise an explicit link.

## Review gates

Actual browser render and interactions, font loading, desktop/narrow layout, reduced motion, print rules, keyboard and error states. Independent design critique plus Impeccable detector; fix material findings before showing the user. No claim of production readiness or clinical validation.
